# SQL Projects

Repositório com projetos de análise de dados utilizando SQL e integração com outras ferramentas.

---

## Projetos

### 🗄️ [Adventure Works 2013 — SQL Server + Excel](./adventure-works/)
Extração e tratamento de dados do banco Adventure Works via SQL Server, com criação de View unindo 5 tabelas, importação para o Excel via Power Query e construção de relatório com tabelas dinâmicas e gráficos.

**Ferramentas:** SQL Server · Excel (Power Query · Tabela Dinâmica)

---

### 🐍 [Python + SQL Server Integration](./python-sql-integration/)
Integração entre Python e SQL Server via Jupyter Notebook — inserção de dados no banco via pyodbc e leitura, tratamento e visualização com pandas e matplotlib.

**Ferramentas:** Python · Jupyter Notebook · SQL Server · pyodbc · pandas · matplotlib
